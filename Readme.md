Личный учебный проект: как типы данных хранятся в памяти компьютера.

Что делает программа

- Выводит размеры базовых типов через `sizeof`
- Показывает целые числа в прямом, обратном и дополнительном коде
- Показывает двоичное представление `float` и `double` (стандарт IEEE 754)
- Демонстрирует работу с битами: `|`, `&`, `^`

Как собрать

Нужен компилятор C++ (g++ или clang++).

```bash
g++ -std=c++17 main.cpp -o program
./program
